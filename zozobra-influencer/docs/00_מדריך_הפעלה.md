# מדריך הפעלה: לילו × ZOZOBRA, צעד אחרי צעד

המדריך הזה בלי מונחים טכניים. כל העבודה נעשית מלוח הבקרה בדפדפן.

## מה צריך (פעם אחת)

| שירות | בשביל מה | איפה מקבלים מפתח | עלות משוערת |
|---|---|---|---|
| **Claude** (Anthropic) | המוח: תסריטים, כיתובים, תוכנית שבועית | console.anthropic.com → API Keys | כמה דולרים בחודש |
| **fal.ai** | תמונות, וידאו, סנכרון שפתיים, אימון הפנים | fal.ai → Dashboard → Keys | לפי שימוש (בערך 1–3$ לסרטון) |
| **ElevenLabs** | הקול של לילו | elevenlabs.io → Profile → API Keys | מנוי Creator ומעלה |
| **Instagram** | פרסום | חשבון Creator מקושר לעמוד פייסבוק ול-Meta Business. ראו `05_publishing_account_setup.md` | חינם |
| **TikTok** | פרסום | developers.tiktok.com → אפליקציה עם Content Posting API | חינם (נדרש אישור של טיקטוק) |

## שלב 1: הפעלת לוח הבקרה

**על המחשב:**
```bash
cd zozobra-influencer
./run.sh
```
אחר כך פותחים בדפדפן את http://localhost:8000

**בענן (פועל 24/7, מומלץ):** הפרויקט כולל `Dockerfile` ו-`railway.json`. ב-Railway:
1. New Project → Deploy from GitHub → בוחרים את הריפו → Root directory: `zozobra-influencer`.
2. מוסיפים Volume שמחובר ל-`/data`, שם נשמרים כל הסרטונים והנתונים.
3. ב-Variables מעתיקים את כל השורות מ-`.env.example` וממלאים את המפתחות.
   **חובה להגדיר `PANEL_PASSWORD`.** שם המשתמש בכניסה הוא `lilo`.

## שלב 2: למלא מפתחות ולבדוק
1. ממלאים את המפתחות בקובץ `.env`, או ב-Variables אם עובדים בענן.
2. בלוח הבקרה עוברים ללשונית **הקמה** ולוחצים **"בדוק חיבור אמיתי"**.
   כל שורה ירוקה מחוברת. ליד שורה אדומה כתוב מה בדיוק לעשות.

## שלב 3: ליצור את לילו (בערך 30 דקות, פעם אחת בלבד)
בלשונית **הקמה**:
1. **"צור 8 מועמדות"** ובוחרים את התמונה שהיא "היא" (לוחצים "זו היא").
2. **"צור גיליון"**: נוצרות 30 תמונות שלה מכל זווית.
   עוברים עליהן ומוחקים כל תמונה עם ידיים שבורות או פנים אחרות.
3. **"אמן"**: אחרי 5–10 דקות מודל הפנים שלה מוכן ונשמר אוטומטית.
4. **"צור קול"**: מקשיבים לדוגמאות. אם הקול לא מתאים, לוחצים שוב.

## שלב 4: כל שבוע (בערך 30 דקות עבודה)
1. **תכנון שבועי**: כותבים על מה השבוע, למשל "בנגקוק היט + דייט נייט בחמישי", ולוחצים "צור".
   אפשר גם לסמן תכנון אוטומטי, ואז זה רץ לבד בכל יום ראשון ב-10:00.
2. **לוחות תוכן**: עוברים על התוכנית ולוחצים **"הפק את כל השבוע"**.
3. **לוח בקרה**: כל פוסט מחכה לאישור. פותחים, **צופים בסרטון עד הסוף**, מתקנים כיתוב אם צריך ולוחצים **אשר**.
4. המערכת מפרסמת לבד בשעה שנקבעה. היא בודקת את התור כל 15 דקות.

## שלב 5: כל יום (5 דקות)
- **תגובות**: לוחצים "משוך ונסח", עוברים על התשובות שלילו ניסחה ושולחים.
  תלונות, אלרגיות, כשרות והזמנות מסומנות להעברה לצוות המסעדה.
- **ביצועים**: הנתונים מתעדכנים כל לילה, והמוח לומד מהם לשבוע הבא.

## מעבר לאוויר
כל עוד `DRY_RUN=true`, שום דבר לא מתפרסם ולא מחויב כסף. מסך הבדיקה מציג רק מה *היה* קורה.
כשכל השורות בלשונית "הקמה" ירוקות ועשיתם שבוע ניסיון, משנים ל-`DRY_RUN=false`.

- לא קונים עוקבים, לא עושים לייקים או עוקבים אוטומטיים, ולא משתמשים בתוכנות פרסום לא רשמיות.
